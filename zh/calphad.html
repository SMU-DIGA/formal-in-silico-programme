01

模型

体系二元 A–B，温度与压力固定；成分 x = xB ∈ [0, 1]。每个相给出每摩尔原子的 Gibbs 能 G(x)，与 pycalphad 的 GM 相同。
溶体一个混合亚点阵，其余亚点阵只有空位：理想混合 RT(x log x + (1 − x) log(1 − x)) 加 Redlich–Kister 过剩项 x(1 − x) Σ Lk(1 − 2x)k。
化合物化学计量化合物：只在一个精确成分（例如 2/3）处存在。
参数T 的分段 SGTE 表达式。驱动选出温度区间、展开函数引用；每一项是 c·Tn 或 c·Tn log T，c 是 TDB 中十进制串的精确乘积。
暂不支持磁性、有序–无序、间隙相，多个混合亚点阵，三个以上组元。这些相被跳过并在报告中列出；结论只对参与计算的相成立。

证书认证的是证书中写明的精确模型。把 TDB 文件翻译成这个模型由不受信任的驱动完成（假设 A-CAL-01）；基准把每个相的 G(x) 与 pycalphad 比较，相对误差 10⁻¹²。

02

证书给出什么

平衡 Gibbs 能 G*(x₀) 是所有可行配置总 Gibbs 能的下确界：可行配置是任意有限个（相、成分、摩尔分数），总成分等于 x₀。几何上，它是各相曲线的下凸包在 x₀ 处的值。

平衡是一个可行配置加一条公切线 ℓ(y) = μA(1 − y) + μBy：切线在所有相的下方，并且经过这个配置；μA、μB 是化学势。Lean 证明了平衡使总 Gibbs 能最小（CAL-C02），并且平衡总是存在（CAL-C03）。

Gibbs 能最小化程序可能停在局部极小，漏掉一个相或一个混溶隙。检查器的结论针对任意可行配置与任意平衡，所以这类错误只会让检查失败或区间变宽，不会给出错误的结论。

行Lean 定理保证的内容
G_OK lo hiG*(x₀) ∈ [lo, hi]：任意可行配置的总 Gibbs 能 ≥ lo，证书中的配置 ≤ hi。
MU_OK A|B lo hi任意平衡的化学势都在这个区间内。
WINDOW 相 a b任意平衡中，该相的每个成分都落在它的某个窗口内。
ABSENT 相该相不出现在任何平衡中。
EXISTS平衡存在，所以上面的结论不是空话。
EPS、KAPPA、FRAC诊断量：驱动的切线在各相下方多远，窗口判据所用的切线误差界，证书自己的配置。

04

检查器如何工作

全程用精确有理数。驱动只提供候选切线、候选配置与探测点。

  1. 1

    参数区间

    log T 用与 mini-DFT 共用的有理级数上下界包住；每个溶体相写成有理多项式加理想混合项，舍入误差一致有界。

  2. 2

    所有相下方的分支定界

    在每个区间上，G − ℓ 的下界由多项式的精确 Taylor 系数、混合项的二次下界（CAL-C01）与二次函数的精确最小值给出。结果 e ≤ 0 从下方界住所有相。

  3. 3

    G* 的区间

    任意可行配置的总 Gibbs 能 ≥ ℓ(x₀) + e（CAL-C02）；证书中的配置（摩尔分数按杠杆定律）给出上端。

  4. 4

    化学势

    任意平衡的切线在 x₀ 处落在 G* 的区间内，并且在两侧探测点处不高于各相；由此确定斜率，进而得到 μA、μB。

  5. 5

    成分窗口

    任意平衡的切线与证书的切线相差不超过 κ，所以出现的相满足 G − ℓ ≤ κ。第二遍分支定界排除下界大于 κ 的区间，剩下的就是窗口。

二分规则只影响速度与精度。可靠性只依赖证明中检查的两件事：被排除的区间下界都高于阈值，区间覆盖 [0, 1]。

交叉校验与辅助证据

  • 每个相在 x = k/20 处的 G(x)，对照 pycalphad 的 calculate相对误差 ≤ 10⁻¹²
  • Al–Zn（Mey 1993）、Pb–Sn（Ngai–Chang 1981）、Cu–Mg 共 17 个平衡，对照 pycalphad 的 equilibrium：成分 / Gibbs 能< 10⁻⁶ / < 10⁻⁵ J/mol
  • pycalphad 的 GM、MU 与平衡相成分落在 Lean 的区间与窗口内
  • 篡改证书检查失败，或结论仍然正确
  • 每个平衡的检查时间0.1 – 6 秒
  • AddressSanitizer 与 UBSan 下的驱动，包括读取 pycalphad 的其他测试数据库无报错

08

缺口

  • 从 TDB 文件到被认证的模型选温度区间、展开函数引用、判断相的类型都由驱动完成，不在可信链内（A-CAL-01）；基准把结果与 pycalphad 对照。
  • 单相区的化学势区间宽约 √(G″·|EPS|)，即 10⁻⁴ 到 10⁻³ J/mol，而两相区约 10⁻⁹ J/mol。收紧需要 G 在 x₀ 处的导数区间（C1 的一项）。
  • 磁性、有序–无序、间隙、亚点阵与多元模型Lean 中尚未定义。驱动跳过这些相并列出；结论只对参与计算的相成立。
  • C 驱动本身网格搜索与 Newton 迭代不受信任（T0），报告中如实标明；所有结果都经过检查器。
