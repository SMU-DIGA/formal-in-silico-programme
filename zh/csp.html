01

问题

体系三维空间中 N 个同种原子（2 ≤ N ≤ 200），零压强下的自由团簇。每一对原子都通过 Lennard-Jones 势相互作用，写成距离平方 s = r² 的函数：φ(s) = 4ε(σ¹²/s⁶ − σ⁶/s³)，不截断。
能量E(x) = ½ Σi≠j φ(sij)。能量、梯度与 Hessian 都是坐标的有理函数，检查器精确计算的正是 Lean 中推理的那个公式（CSP-C01）。
对称性E 在转动与反射、平移、原子重新编号下不变，所以极小在 ℝ3N 中从不孤立：它是模这些运动的极小，6 个轨道方向由 Eckart 规范固定。
输入ε、σ 与每个坐标在证书中都是精确的二进有理数 m·2e，即搜索器实际得到的 double。检查器以 PROBLEM 行回显问题，供调用者比对。

03

证书如何工作

搜索器停在一个梯度很小但不为零的点 x₀。证书证明在它给出的半径内有一个真正的极小 x*：在构型空间的合适截面上，能量在一个小球内强凸。所有检查都是精确有理数运算，搜索器的浮点数只是数据。

  1. 1

    Eckart 规范

    转动与平移使 Hessian 在 6 个方向上奇异。检查器在过 x₀ 的 Eckart 截面上工作：相对 x₀ 没有净平移、没有净转动的位移。Lean 证明任何构型都可以经转动与平移移进这个截面且离 x₀ 不更远，所以截面上的严格极小就是模欧氏运动的严格极小（CSP-D01）。

  2. 2

    原子保持分开

    在半径 R 的球内，任一对原子的相对位移不超过 √2·R，所以每个距离平方都大于显式的 slo > 0。检查器据此用 φ″、φ‴ 的显式界和中值定理，算出每一对原子的 Hessian 在球内最多下降多少。

  3. 3

    梯度小

    ‖∇E(x₀)‖ ≤ g：每一项向下舍入到 2⁻¹⁰⁰ 的格点，舍入误差计入界中。

  4. 4

    精确的正定性

    x₀ 处的 Hessian 减去成对损失、加上 6 个轨道方向上的罚项 κ、再减 μ·I，用 Schur 补消元证明半正定：每一步舍入到 2⁻¹⁰⁰ 的格点并在对角线上减去舍入误差（在 Lean 中证明可靠）。于是 E 在截面内整个球上 μ-强凸。

  5. 5

    强凸球定理

    若 g < μR，球内恰有一个驻点，即唯一的极小点，离 x₀ 不超过 g/μ，能量在 [E(x₀) − g²/(2μ), E(x₀)] 中（CSP-D02）。检查器自己精确包住 E(x₀)，这就是输出的区间。

  6. 6

    相同或不同

    same 记录给出一个置换、一个精确正交的有理矩阵（带符号的 Cayley 变换，精确检查 QᵀQ = I）和一个平移，把一个候选映进另一个的唯一性球内，反之亦然。能量区间不相交的两个极小无需更多数据就是不同的结构。

区间为什么这么窄：搜索器每次弛豫最后用 Newton 法把梯度降到约 10⁻¹³，所以 g²/(2μ) 约为 10⁻²⁴；区间宽度由 2⁻¹⁰⁰ 格点的舍入和输出小数的向外舍入决定。唯一性半径为 2×10⁻⁵ 到 1.7×10⁻⁴ σ，受 Lennard-Jones Hessian 变化之快的限制。

04

搜索，以及关于它证明了什么

搜索器 build/mini-csp（C11，双精度）按 Wang、Lv、Zhu、Ma 发表的算法（PRB 82, 094116, 2010；CPC 183, 2063, 2012）实现，只依据论文，不参考任何现有程序。每一代把每个粒子弛豫（BFGS，再用带规范罚项的 Newton 法收尾），按能量排序，把最差的一部分换成新的随机结构，其余按粒子群更新 v ← ωv + c₁r₁(p − x) + c₂r₂(g − x)、x ← x + v 移动。排序后的原子间距离作为指纹，只用来提出合并，由检查器决定。

搜索器做的一切都不进入可信链：它的错误只会让它漏掉结构，不会产生错误的认证结论。另外，Lean 在账本中写明的理想化假设下证明了搜索算法本身的两条性质：

  • 粒子群稳定区域（CSP-A01）吸引子固定、随机数理想均匀时，粒子的均值收敛当且仅当 |ω| < 1 且 0 < c₁ + c₂ < 4(1 + ω)；均方收敛当且仅当落在一个更小的区域内，c₁ = c₂ 时即 Poli 的 0 < c < 24(1 − ω²)/(7 − 5ω)。两者都是充要条件，经二次、三次多项式的 Schur–Cohn/Jury 判据证明。Clerc–Kennedy 缺省参数 ω = 0.7298、c₁ = c₂ = 1.49618（以及它们的精确 double 值）在两个区域内。
  • 随机补充找到全局最优的吸引盆（CSP-A02）若每一代至少有一个独立的、在包含全局极小的盒子中均匀抽取的结构，t 代后仍没有一个落在其 δ 邻域内的概率不超过 (1 − pδ)t → 0，pδ > 0。只是渐近结论，不给有限次运行的保证。

致谢。搜索算法来自 CALYPSO，作者是王彦超、吕健、朱力、马琰铭（吉林大学）。正是他们对粒子群结构预测清晰的公开描述，才使独立、可验证的实现成为可能；mini-CSP 是向这项工作的致敬，不是它的替代。

07

缺口

  • 全局最优BEST 是这次运行找到的最低认证极小。证明它是全局最优需要构型空间上的分支定界证书（计划阶段 5，CSP-B05）。
  • 晶体、对称性与压强目前只有零压强的自由团簇。对称约束生成与对称性证书、周期晶胞、压强、多组元体系在阶段 2、3（CSP-B03、C02、D03、D04）。
  • 搜索中的去重same 记录目前只由 --same-demo 产生；搜索中指纹提出的合并还没有置换与转动的证书，只保留一个代表（计划用置换匹配加 Kabsch 对齐）。
  • 搜索器的代码不受信任（T0）。粒子群单步计划在 IEEE 754 模型下做 Frama-C/WP 证明（CSP-P01）；搜索循环、分发与断点续跑写 TLA+ 规范并做 trace validation（CSP-L01）；另加带 JSON 输出的 fis csp 命令（CSP-L02）。
  • 理想化模型之外CSP-A01、A02 假设吸引子固定、随机数理想、坐标为实数；均方结论只覆盖 p = g。阶段 1 的搜索器用 ω = 0.7、c₁ = c₂ = 1.5，按证明的公式在两个区域内，但不是 defaults_stable 的那组常数；它还截断速度，这不在模型之内。
